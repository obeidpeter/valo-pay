# Evidence-led usability improvement · 22 September 2026

This release improves operational review, correction and recovery in the actual Valo Pay sandbox. It does not activate a financial service. Human learnability, efficiency, memorability and satisfaction results remain **not measured**; the evidence so far is source review, synthetic engineering tests and browser inspection.

The five components are kept separate. There is no combined usability score, certification or claim that automated testing predicts human satisfaction. The small iterative study and delayed retest are ready to run with recruited participants.

The local evidence bundle is named **Valo_Pay_Usability_2026-09-22**. Before/after PNGs use the isolated local server at desktop (1440), tablet (768) and phone (390) CSS-pixel widths. The audit records a correction to the paginated synthetic fixture; totals across phases are not comparative performance evidence. Its gallery identifies changed interactions and unchanged coverage screens. These are emulated viewports, not physical-device evidence. Screenshots contain synthetic records only and are delivered separately from source publication.
