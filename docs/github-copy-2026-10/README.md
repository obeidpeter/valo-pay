# Documents for the earlier GitHub copy (3 to 5 October 2026)

Until 5 October 2026 this repository held a one-off copy of the Valo Pay app at the repository root. It was not synced with the Replit workspace, so changes made here never reached Replit. On 5 October 2026 the repository was switched to the Replit app (`artifacts/valo-pay/`), and the changes the owner asked for that were missing on Replit were rebuilt there.

These documents describe that earlier copy and are kept for reference. The code they describe is in the git history (last version: commit 79a20ae). Links inside them point to the old layout.

- `README-github-copy.md`, `RELEASE_SCOPE.md`, `UI_CONTRACT.md`: setup, scope and template contract of the earlier copy.
- `content/`: the content guide, copy inventory, copy review and before-and-after walk of the October copy rewrite. The writing rules in the content guide (British and Nigerian English, plain words, honest money and consent wording) still apply to new wording.
